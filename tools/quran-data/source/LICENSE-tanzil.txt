Terms for the Tanzil files in this directory
============================================

Retrieved 2026-11-15. Copied verbatim from the pages and files named below.

---------------------------------------------------------------

is also reproduced, as comments, in the CREATE TABLE statement of the generated
data/src/main/assets/quran.db (the terms require it in derived files):

Terms of Use as stated on https://tanzil.net/download/ :

  Permission is granted to copy and distribute verbatim copies of the Quran
  text provided here, but changing the text is not allowed. The text can be
  used in any website or application, provided that its source (Tanzil
  Project) is clearly indicated, and a link is made to tanzil.net to enable
  users to keep track of changes.

https://tanzil.net/docs/text_license states the same notice (with
"Copyright (C) 2007-2021 Tanzil Project") and that it "is applied to, and is
included in all copies of Tanzil Quran text".

Licence: Creative Commons Attribution 3.0,
https://creativecommons.org/licenses/by/3.0/

2. quran-data.xml (Tanzil Quran Metadata, version 1.0)
------------------------------------------------------

No separate terms file is shipped with the metadata. The only statement is the
root element of the file itself:

  <quran type="metadata" version="1.0" copyright="(C) 2008-2009 Tanzil.info" license="cc-by">

and https://tanzil.net/docs/quran_metadata, which links the file
(http://tanzil.net/res/text/metadata/quran-data.xml) without further terms.
Read as: Creative Commons Attribution (version not stated), attribution to
the Tanzil Project.

Attribution the app must show: "Quran text and metadata: Tanzil Project,
https://tanzil.net" (CC BY 3.0).
